## Mission briefing

Somebody gave CJ directions to a house that was demolished yesterday. He drives there anyway. That's a dangling reference: the address is valid-looking, the building is gone.

**Mission:** learn which objects you're allowed to point at.

## Views don't own

`std::string_view` is a pointer and a length. If the `std::string` it views dies or reallocates, the view dangles. The same goes for spans, iterators after `push_back`, and references to vector elements.

## Return by value

When in doubt, return owning values. Copy elision and moves make it cheap.

Sources: [cppreference: reference initialization, lifetime](https://en.cppreference.com/w/cpp/language/reference_initialization), Core Guidelines F.43, [CppCon 2018: Nicolai Josuttis, string_view](https://www.youtube.com/watch?v=sVIi9y_sZ5o)
