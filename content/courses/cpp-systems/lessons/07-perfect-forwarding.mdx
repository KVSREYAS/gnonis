## Mission briefing

You're the middleman. Packages arrive, some marked FRAGILE (lvalues, don't touch) and some marked TAKE IT (rvalues). Your job is to pass each one on with its label intact.

**Mission:** don't peel off the labels.

## Reference collapsing

For `template<class T> void f(T&& x)`: passing an lvalue `int` deduces `T = int&`, and `int& &&` collapses to `int&`. Passing an rvalue deduces `T = int`.

## emplace without copies

Sources: [cppreference: std::forward](https://en.cppreference.com/w/cpp/utility/forward), Meyers, *Effective Modern C++*, Items 24–30

  tests={"#include \"check.h\"\n\n#include <memory>\n#include <string>\nint main() {\n    int calls = 0;\n    CHECK(call_logged(calls, [](int a, int b) { return a + b; }, 2, 3) == 5);\n    auto p = std::make_unique<int>(42);\n    auto take = [](std::unique_ptr<int> q) { return *q; };\n    CHECK(call_logged(calls, take, std::move(p)) == 42);\n    CHECK(p == nullptr);\n    int x = 1;\n    auto ref = [](int& r) -> int& { return r; };\n    call_logged(calls, ref, x) = 9;\n    CHECK(x == 9 && calls == 3);\n    return 0;\n}\n"}
