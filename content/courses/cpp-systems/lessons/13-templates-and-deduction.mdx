## Deduction cases

`const int ci = 1;` then `f(ci)`:

- `template<class T> void f(T)` gives T = int (const dropped: it's a copy)
- `template<class T> void f(T&)` gives T = const int
- `template<class T> void f(T&&)` gives T = const int&
