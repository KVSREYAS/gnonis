## Writing constraints

```cpp
template <class T>
concept HasSize = requires(const T& t) { { t.size() } -> std::convertible_to<std::size_t>; };

template <HasSize C> auto count(const C& c) { return c.size(); }
```
Pass an `int` and the error says *constraints not satisfied: HasSize<int>*, not a template stack trace.
