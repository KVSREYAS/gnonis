## Mission briefing

Why do the maths during the heist when you can do it while planning? Every value the compiler computes is one the CPU never has to.

**Mission:** move the work to compile time.

## if constexpr

```cpp
template <class T> constexpr std::size_t bytes_of() {
  if constexpr (std::is_same_v<T, bool>) return 1;
  else return sizeof(T);
}
```
The discarded branch is never instantiated.
