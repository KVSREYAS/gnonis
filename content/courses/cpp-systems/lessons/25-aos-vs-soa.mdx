  - "AoS (`std::vector<Particle>`) interleaves fields, so a loop over x drags y, z, mass and id through the cache too."
  - "SoA (`struct { std::vector<float> x, y, z; }`) packs each field contiguously: 100% useful bytes and easy SIMD."
  - "Mike Acton: \"where there is one, there are many\". Design for the transform you run on the whole batch."
