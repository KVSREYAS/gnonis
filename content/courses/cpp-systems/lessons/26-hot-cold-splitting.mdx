missionIntro: "Fields used every frame (hot) and fields used once in a blue moon (cold) shouldn't share cache lines."
keyIdeas:
  - "Move rarely used fields (names, debug info, config) into a separate cold array indexed the same way."
  - "Smaller hot structs mean more objects per cache line and fewer misses per update."
  - "Measure first: splitting only helps if the hot loop is memory-bound."
