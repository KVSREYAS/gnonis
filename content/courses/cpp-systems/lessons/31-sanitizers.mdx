  - "Run tests under ASan+UBSan in CI, and run concurrent code under TSan separately (TSan and ASan can't be combined)."

## Mission briefing

The UB Underground hates witnesses. Sanitizers are witnesses: cameras on every corner that shout the moment someone misbehaves.

**Mission:** install cameras before the heist, not after.
