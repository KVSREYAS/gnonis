  - "relaxed gives atomicity only, which suits counters but never flags that guard other data."

## Mission briefing

Concurrency Casino's chip counter is atomic, so nobody double-spends. But when you shout "the package is ready", does your partner actually see the package?

**Mission:** learn acquire and release.
