## Write it

Note: this exercise needs an x86-64 runner (SSE2 is baseline there, no flags needed). Sources: [Intel Intrinsics Guide](https://www.intel.com/content/www/us/en/docs/intrinsics-guide/), Agner Fog, [Optimizing software in C++](https://www.agner.org/optimize/optimizing_cpp.pdf)
