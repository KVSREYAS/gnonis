keyIdeas:
  - "C = A·B with i-j-k order strides down B's columns (cache-hostile). i-k-j order streams rows of B and C contiguously, which vectorises well."
  - "Tiling keeps blocks of A, B and C in cache and reuses each loaded element many times."
  - "FLOPs = 2·M·N·K. Arithmetic intensity determines whether you're memory- or compute-bound."
