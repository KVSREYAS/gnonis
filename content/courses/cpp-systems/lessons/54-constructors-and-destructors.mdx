## Birth and death

Constructors run when the object is created. Destructors run in reverse order when it dies.

![Object lifeline: constructor builds members from the init list, destructor runs at scope end](/diagrams/cpp-systems/oop/02-constructors-and-destructors.png)

## this and const

Inside a method, `this->fuel_` and plain `fuel_` mean the same thing. Mark a method `const` when it only reads.

<SpotBug
  id="const-method"
  prompt="Which line fails to compile?"
  code={"class Car {\n    int fuel_ = 10;\npublic:\n    int fuel() const { return fuel_; }\n    void refill() const { fuel_ = 100; }\n};"}
  bugLine={5}
  explanation="A const method can't modify members. Drop the const from refill."
