## Static members

One copy for the whole class, however many objects you create.

## Operators and friends

`a + b` on your type just calls `operator+(a, b)`. Declaring a function `friend` inside the class lets it read private members.

<Code
  id="money-ops"
  devices={["desktop"]}
  language="cpp"
  prompt="Write `class Money` holding private `long cents_`, with constructor `Money(long cents)`, `long cents() const`, `operator+` and `operator==` (as members or friends), and a friend `std::ostream& operator<<(std::ostream&, const Money&)` printing like `$12.05`. Assume amounts are not negative."
  starter={"#include <ostream>\nclass Money {\npublic:\n    Money(long cents) {}\n    long cents() const { return 0; }\n    Money operator+(const Money& o) const { return Money(0); }\n    bool operator==(const Money& o) const { return false; }\n    friend std::ostream& operator<<(std::ostream& os, const Money& m) { return os; }\n};\n"}
  visibleTests={"#include \"check.h\"\n#include <sstream>\nint main() {\n    Money a(150), b(275);\n    CHECK((a + b).cents() == 425);\n    return 0;\n}\n"}
  tests={"#include \"check.h\"\n#include <sstream>\nint main() {\n    Money a(150), b(275);\n    CHECK((a + b).cents() == 425);\n    CHECK(a + b == Money(425) && !(a == b));\n    std::ostringstream s; s << Money(1205) << ' ' << Money(7) << ' ' << Money(300);\n    CHECK(s.str() == \"$12.05 $0.07 $3.00\");\n    return 0;\n}\n"}
  solution={"#include <ostream>\n#include <iomanip>\nclass Money {\n    long cents_;\npublic:\n    Money(long cents) : cents_(cents) {}\n    long cents() const { return cents_; }\n    Money operator+(const Money& o) const { return Money(cents_ + o.cents_); }\n    bool operator==(const Money& o) const { return cents_ == o.cents_; }\n    friend std::ostream& operator<<(std::ostream& os, const Money& m) {\n        return os << '$' << m.cents_ / 100 << '.' << std::setw(2) << std::setfill('0') << m.cents_ % 100;\n    }\n};\n"}
  hints={["`cents_ % 100` needs two digits: std::setw(2) and std::setfill('0').", "operator<< is a friend so it can read cents_."]}
  explanation="Overload operators only where the meaning is obvious. Money + Money is obvious; Car * Car is not."
