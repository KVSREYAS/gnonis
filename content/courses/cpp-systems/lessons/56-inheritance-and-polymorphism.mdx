## Mission briefing

Bikes, cars and planes are all vehicles. Shout "honk" at any of them and each makes its own noise.

**Mission:** one interface, many vehicles.

## Virtual calls

Each class with virtual functions has a table of function pointers (the vtable), and each object carries a hidden pointer to it. That's how the call finds the right version.

![Truck object with a hidden vptr pointing at Truck's vtable, whose honk slot points at Truck::honk](/diagrams/cpp-systems/oop/04-inheritance-and-polymorphism.png)

## Abstract shapes

A pure virtual function `= 0` makes the class abstract: you can't create one directly, only derived classes that implement it.

<Code
  id="shapes"
  devices={["desktop"]}
