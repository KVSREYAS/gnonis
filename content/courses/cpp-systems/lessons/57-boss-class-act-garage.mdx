## Coding task: the enemy wave

Each round, Slime Siege spawns a wave of mixed enemies. The HUD shows how many are in the wave and how much damage they deal together if they all reach you.

<Code

  prompt="Write an abstract `class Enemy` with constructor `Enemy(std::string name)`, `const std::string& name() const`, a pure virtual `int damage() const` and a virtual destructor.   solution={"#include <string>\n#include <memory>\n#include <vector>\n#include <utility>\nclass Enemy {\n    std::string name_;\npublic:\n    Enemy(std::string name) : name_(std::move(name)) {}\n    const std::string& name() const { return name_; }\n    virtual int damage() const = 0;\n    virtual ~Enemy() = default;\n};\nclass Slime : public Enemy {\npublic:\n    Slime(std::string n) : Enemy(std::move(n)) {}\n    int damage() const override { return 5; }\n};\nclass Bat : public Enemy {\npublic:\n    Bat(std::string n) : Enemy(std::move(n)) {}\n    int damage() const override { return 3; }\n};\nclass Wave {\n    std::vector<std::unique_ptr<Enemy>> v_;\npublic:\n    void add(std::unique_ptr<Enemy> e) { v_.push_back(std::move(e)); }\n    int total_damage() const { int t = 0; for (const auto& e : v_) t += e->damage(); return t; }\n    std::size_t size() const { return v_.size(); }\n};\n"}
