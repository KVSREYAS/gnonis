## Arena allocator

`malloc`/`new` must handle any size and any free order, so each call does bookkeeping. When many objects share one lifetime (for example, everything for one request), an **arena** is simpler:

1. Reserve one large block.
2. Keep an **offset**, the first unused byte.
3. To allocate n bytes: round the offset up to the required alignment, return that address, add n.
4. Never free single objects. **Reset** the offset to 0 to free everything at once.

```cpp
void* alloc(size_t n, size_t align) {
    size_t p = (off_ + align - 1) & ~(align - 1);   // round up
    if (p + n > cap_) return nullptr;
    off_ = p + n;
    return buf_ + p;
}
```

Allocation is a few instructions, and objects are contiguous, which helps the cache. Destructors are not run, so store only trivially destructible types or call them yourself.

## SPSC ring buffer

A **ring buffer** is a fixed array used in a circle. **SPSC** means single producer, single consumer: exactly one thread pushes and one thread pops.

State: `head` (next slot to read, written only by the consumer) and `tail` (next slot to write, written only by the producer). Both are `std::atomic<size_t>`.

- push: if `tail - head == capacity`, full. Else write `buf[tail % cap]`, then store `tail + 1` with **release**.
- pop: if `head == tail` (loaded with **acquire**), empty. Else read `buf[head % cap]`, then store `head + 1` with release.

Release/acquire guarantees the consumer sees the item's data before it sees the new `tail`. No mutex is needed because each index has only one writer. With a power-of-two capacity, `% cap` becomes `& (cap - 1)`.

## Thread pool

Creating a thread per task costs tens of microseconds. A **thread pool** creates N workers once and reuses them.

Parts:

1. A queue of tasks (`std::function<void()>`), protected by a mutex.
2. A `std::condition_variable` that sleeping workers wait on.
3. Worker loop: lock, wait until the queue is non-empty or `stop` is set, pop a task, unlock, run it.
4. `submit(task)`: lock, push, unlock, `notify_one()`.
5. Shutdown: set `stop`, `notify_all()`, join every worker.

To return a result, wrap the task in `std::packaged_task` and hand the caller a `std::future`.

N is usually the number of hardware threads (`std::thread::hardware_concurrency()`). More workers than cores adds switching cost without extra speed for CPU-bound work.
