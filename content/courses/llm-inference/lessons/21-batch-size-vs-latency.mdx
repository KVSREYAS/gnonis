## Mission briefing

The bus company wants more riders per trip. Every extra passenger costs almost nothing... until their luggage (the KV cache) fills the aisle.

**Mission:** price the batch-size bargain before Big Smoke does it for you.

## Same weights, more riders

In a memory-bound decode step the GPU streams all the weights from HBM once, whatever the batch size. Each sequence in the batch reuses that same read. So going from batch 1 to batch 16 costs a little extra KV reading and almost nothing else.

Total bytes per step = weights + Σ (context × KV bytes per token).

## The luggage bill

Long contexts change the maths. At batch 64 with 2k tokens each, the KV cache is bigger than the weights, so step time roughly doubles. Push further and you either run out of memory or cross the roofline ridge into compute-bound territory.
