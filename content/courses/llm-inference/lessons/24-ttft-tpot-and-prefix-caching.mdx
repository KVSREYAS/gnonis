## Mission briefing

You run the Cluckin' Bell drive-thru. Customers judge you on two things: how long before the first nugget
appears (TTFT) and how fast the rest follow (TPOT). Also, everyone orders the same combo intro. Pre-cook it.

## Two clocks

**TTFT** covers queueing plus prefill. **TPOT** (or inter-token latency) is the gap between later tokens.

## End-to-end latency

Total time is roughly TTFT plus TPOT for every token after the first.

## Prefix caching

If many requests start with the same system prompt, keep its KV blocks and skip that part of prefill.
vLLM calls it automatic prefix caching, and SGLang uses a radix tree (RadixAttention).

<Predict
  id="prefix-saving"
  devices={["phone","desktop"]}
  prompt={"Every request has a 2,000-token shared system prompt plus a 200-token user message. With a warm prefix cache, what percentage of prefill tokens are skipped?"}
  answer={90.9}
  tolerance={{"mode":"absolute","value":0.5}}
  unit="%"
  explanation="2000 / 2200 = 90.9% of prefill tokens come from the cache."
/>

## Street wisdom

Rating a server by tokens per second alone is like rating a restaurant by meals per hour. Great, until
your table has waited 40 minutes.
