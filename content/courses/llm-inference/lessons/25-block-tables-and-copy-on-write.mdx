## Mission briefing

Four crew members want to rob the same bank, and each insists on their own copy of the floor plan. Ridiculous.

**Mission:** let them share one copy, and photocopy a page only when someone scribbles on it.

## Reference counts

Each physical block records how many sequences point at it. Parallel sampling (n > 1) maps every sample's logical prompt blocks to the same physical blocks. When a sample finishes, it decrements the counts, and blocks at zero return to the free pool.

## Copy on write

The last prompt block is usually half full. When sample 2 writes its first new token there, vLLM copies just that one block and bumps the counts. Everything else stays shared.

## Beams share more

Beam candidates share generated text as well. The vLLM paper measured 37.6–55.2% savings for beam search versus 6.1–9.8% for parallel sampling.

Source: [Kwon et al., §4.4 and §6.3](https://arxiv.org/abs/2309.06180)
