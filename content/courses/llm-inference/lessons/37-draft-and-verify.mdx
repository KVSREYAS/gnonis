## Mission briefing

Big Smoke takes forever to decide every turn. So a kid on a BMX rides ahead and shouts four turns at
once. Smoke checks them all in one glance, keeps the right ones, and corrects the first wrong one. Same
route, fewer pauses.

## Guess, then check

A small draft model proposes several tokens. The big target model scores all of them in **one** forward
pass, which costs about the same as one decode step because decode is memory-bound.

![Draft model proposes four tokens; the target accepts three, rejects one and resamples a replacement](/diagrams/llm-inference/09-speculative-decoding/01-draft-and-verify.png)

## How many tokens per pass?

If each draft token is accepted with probability alpha and the draft proposes gamma tokens, the expected
number of tokens per target pass is (1 - alpha^(gamma+1)) / (1 - alpha).

<Predict
  id="expected-tokens"
  devices={["phone","desktop"]}
  prompt="Acceptance rate alpha = 0.8 and the draft proposes gamma = 4 tokens. Expected tokens produced per target-model pass?"
  answer={3.36}
  tolerance={{"mode":"absolute","value":0.05}}
  unit="tokens"
  hint="(1 - 0.8^5) / (1 - 0.8)"
  explanation="(1 - 0.32768) / 0.2 = 3.36. Formula from Leviathan et al. 2023, Eq. 1."
/>

## When it backfires

Speculation spends spare compute to save memory-bound steps.

<MCQ
  id="when-bad"
  devices={["phone","desktop"]}
  prompt="When does speculative decoding help least?"
  options={["Batch 1 on a big GPU","Very large batches where the GPU is already compute-bound","Code completion with repetitive text","When the draft model is very well aligned"]}
  answer={1}
  explanation={"Speculation spends spare compute. At high batch there is no spare compute left, so the extra verification work can slow you down."}
/>

## Street wisdom

Variants worth knowing: Medusa (extra decoding heads), EAGLE (feature-level drafting) and prompt-lookup
or n-gram drafting.
