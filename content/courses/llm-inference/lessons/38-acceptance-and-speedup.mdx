## Tokens per pass

High acceptance means long runs of accepted drafts, so each target pass yields several tokens. Low
acceptance means most passes stop early, often after the first draft, and the pass yields little more
than a normal step. Counting the correction token, every pass yields at least one token.

## What controls α

α is how often the draft's token survives the accept rule. It depends on three things:

- **How well the draft matches the target.** A draft distilled on the target's own outputs agrees with it much more often than an off-the-shelf small model does.
- **How predictable the text is.** Code, structured output and quoted material score high α. Creative writing at high temperature scores low.
- **Sampling settings.** With sampling, the chance of acceptance is min(1, p/q) per token, so a draft that is overconfident where the target is unsure gets rejected more often.

The draft must use the same tokenizer as the target, or its tokens can't be checked position by position.

## The cost of drafting

Drafting isn't free. Every draft token costs a step of the draft model, and the verify pass, which
checks several positions at once, is a little slower than a normal one-token step. So the real speedup
is always below the number of tokens per pass, and drafting more tokens only helps while late drafts
still have a fair chance of surviving.

**Distilling** a draft means training the small model to imitate the target's output probabilities. Its guesses then agree with the target more often, which raises α.

The accept rule from the last lesson is what keeps all of this exact: a draft is accepted with
probability min(1, p / q), and a rejected one is replaced by a sample from what the draft
under-proposed. The exercise below builds both pieces.

Source: [Leviathan et al. 2023](https://arxiv.org/abs/2211.17192)

  devices={["desktop"]}

  prompt={"Speculative sampling keeps the target's distribution exactly. For one draft token, the target gives it probability p and the draft gave it q. Write accept(p, q, u): accept when u < min(1, p / q), where u is a uniform random number in [0, 1). If a draft is rejected, the replacement is sampled from residual(p_dist, q_dist): max(0, p_i − q_i) for each token, rescaled to add up to 1. Write both."}
  starter={"def accept(p, q, u):\n    # Greedy habit: accept only if the target likes it at least as much.\n    return p >= q\n\ndef residual(p_dist, q_dist):\n    # Resample from the target as-is.\n    return list(p_dist)\n"}
  tests={"def close(a, b):\n    return all(abs(x - y) < 1e-9 for x, y in zip(a, b))\n\ndef test_target_likes_it_more_always_accept():\n    assert accept(0.5, 0.25, 0.99) is True\n\ndef test_partial_acceptance():\n    \"\"\"target likes it a quarter as much as the draft did\"\"\"\n    assert accept(0.1, 0.4, 0.2) is True\n    assert accept(0.1, 0.4, 0.3) is False\n\ndef test_residual_keeps_only_what_draft_undersold():\n    assert close(residual([0.5, 0.3, 0.2], [0.2, 0.6, 0.2]), [1.0, 0.0, 0.0])\n\ndef test_residual_rescales():\n    assert close(residual([0.4, 0.4, 0.2], [0.2, 0.2, 0.6]), [0.5, 0.5, 0.0])\n"}
  solution={"def accept(p, q, u):\n    return u < min(1.0, p / q)\n\ndef residual(p_dist, q_dist):\n    r = [max(0.0, p - q) for p, q in zip(p_dist, q_dist)]\n    total = sum(r)\n    return [x / total for x in r]\n"}
  hints={["When p >= q, the ratio is at least 1, so every u is accepted.", "Sum the clipped differences, then divide each by the sum."]}
  explanation={"Tokens the draft over-proposes are accepted only part of the time, and on rejection the replacement comes only from tokens the draft under-proposed. The two pieces add up to exactly the target's distribution, which is why lossless speculative decoding is allowed even where outputs must match the approved model."}
