## Mission briefing

Welcome to the Server Strip dealership. Four rides on the lot: a reliable sedan, a tuned street racer, a factory-built supercar, and a scooter that runs on anything.

**Mission:** match each customer to a ride.

## Datacenter engines

**vLLM** is the default open-source server. **SGLang** adds RadixAttention and a structured-generation frontend, and shines on prefix-heavy and agent workloads. **TensorRT-LLM** compiles models into optimised NVIDIA engines with in-flight batching and FP8/FP4.

## Local engine

**llama.cpp** is pure C/C++ with GGUF files and runs everywhere from a Raspberry Pi to a Mac Studio. Ollama and LM Studio wrap it.

Sources: [vLLM](https://github.com/vllm-project/vllm), [SGLang](https://github.com/sgl-project/sglang), [TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM), [llama.cpp](https://github.com/ggml-org/llama.cpp)
