## Mission briefing

Capstone Peak. No more theory: you're building the whole operation from the ground up.

**Mission:** draw the blueprint before you pour concrete.

## The organs

Serving engines like vLLM split cleanly into an async API front, a scheduler with waiting, running and swapped queues, a KV block manager, a model runner that executes batched forwards, and a sampler plus detokenizer that stream tokens back.

## How big?

Little's law tells you how many sequences you'll hold at once, and so how many KV blocks you need.

Source: [vLLM architecture overview](https://docs.vllm.ai/en/latest/design/arch_overview.html)
