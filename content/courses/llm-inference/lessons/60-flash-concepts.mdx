## Where naive attention loses time

A straightforward implementation does three kernels:

1. S = Q K^T, write S (T x T) to HBM
2. read S, compute P = softmax(S), write P to HBM
3. read P, compute O = P V

For T = 8,192 in FP16, one head's S is 8,192 x 8,192 x 2 bytes = 128 MiB, written and read twice. The arithmetic is small compared with that traffic, so the kernels are memory-bound. Memory use is also quadratic in T.

The fix is to never store S or P in HBM.

![Naive attention round-tripping S and P through HBM](/diagrams/llm-inference/08-flash-attention/01-the-hbm-bottleneck.png)

## Online softmax

Softmax seems to need the whole row first, because of the max and the sum. **Online softmax** processes a row in pieces, keeping:

- m: largest score seen so far
- l: sum of exp(score - m) so far
- o: weighted sum of values so far

For each new score s with value v:

1. m_new = max(m, s)
2. rescale old totals by c = exp(m - m_new): l = l x c, o = o x c
3. l += exp(s - m_new); o += exp(s - m_new) x v
4. m = m_new

At the end, output = o / l. This gives exactly the same answer as normal softmax, in one pass.

Check with scores [1, 3]: after 1, m = 1, l = 1. After 3, m = 3, l = 1 x e^-2 + 1 = 1.135. Same as e^-2 + e^0.

![Running max and sum being rescaled](/diagrams/llm-inference/08-flash-attention/02-online-softmax.png)

## Tiling in SRAM

**FlashAttention** combines online softmax with **tiling**:

1. Split Q into row tiles (e.g. 128 rows) and K, V into column tiles.
2. For one Q tile, load it into SRAM.
3. Loop over K/V tiles: load each into SRAM, compute that block of scores, apply the online softmax update to the running m, l and output.
4. After the last tile, divide by l and write the output tile to HBM once.

HBM traffic drops from order T squared to roughly reading Q, K, V and writing O. Memory for scores is only one tile. On real GPUs this gives several times speedups for long sequences, and it is exact, not an approximation.

![Q tile staying in SRAM while K/V tiles stream through](/diagrams/llm-inference/08-flash-attention/03-tiling-in-sram.png)
