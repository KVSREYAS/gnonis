## Mission briefing

One id walks in. Dozens of transformer blocks later, a vote over 128,000 word pieces walks out.

**Mission:** Escort token #644 through every block on Grove Street. Don't let it lose its residual.

## From ids to vectors

The first layer is just a lookup. The **embedding table** is a matrix with one row per vocabulary
entry. Token id 644 selects row 644, a vector of `d_model` numbers (4,096 for Llama 3 8B).

So a prompt of $n$ tokens becomes a matrix of shape $[n \times d_{model}]$. Everything after this
point is matrix maths on that hidden state.

## The block, repeated

A decoder-only transformer stacks $N$ identical **blocks** (32 in Llama 3 8B). Each block does two
things:

1. **Attention** lets every position read from earlier positions.
2. An **MLP** (feed-forward network) transforms each position on its own.

Each half starts with a normalization (RMSNorm in Llama) and ends by *adding* its output back to its
input. That running sum is called the **residual stream**.

## Out come the logits

After the last block, a final norm and the **LM head** (a $[d_{model} \times vocab]$ matrix) turn
each hidden vector into one score per vocabulary entry. These raw scores are **logits**.

For generation, only the logits at the *last* position matter: they rank every possible next
token. Turning them into an actual choice is the next lesson.

Cost check: a forward pass does about **2 FLOPs per parameter per token**, so an 8B model needs
roughly 16 GFLOPs for every token it processes.
