## Mission briefing

Each token walks in with a question (query). Every earlier token wears a name tag (key) and carries a briefcase (value).

**Mission:** Every token in this bar is asking around. Find out who answers, and what they hand over.

## Three projections

Attention lets each position pull information from other positions. Every hidden state $x$ is
multiplied by three learned matrices:

- **Query** $q = xW_Q$: what this token is looking for.
- **Key** $k = xW_K$: what this token offers to be found by.
- **Value** $v = xW_V$: what this token hands over if chosen.

Think of a search engine. Your query is matched against document keys, and you read back a blend
of the matching documents' contents.

## Scores, softmax, mix

For one query, compute a score against every key, turn the scores into weights, and average the
values:

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

$QK^\top$ is an $[n \times n]$ matrix: row $i$ holds how much token $i$ cares about every token.
Softmax runs along each row, so each row's weights sum to 1.

## The scale factor

The $\sqrt{d_k}$ is not decoration. With $d_k = 128$, raw dot products can reach magnitudes that
push softmax into a near one-hot distribution, where it stops learning.

Dividing by $\sqrt{d_k}$ keeps the scores' variance around 1, whatever the head size.
