## The waste

Without a cache, step $t$ of decoding would run the model over all $t$ tokens again, just to get
the last row of attention. Keys and values for the old tokens would be recomputed every single
step, giving quadratic total work for nothing.

They come out identical each time because the causal mask means old tokens never see new ones.

## The cache

So store them. For each layer, keep the $K$ and $V$ vectors of every token so far:

1. **Prefill** computes K and V for the whole prompt and writes them to the cache.
2. Each **decode** step computes $q, k, v$ for the one new token, appends $k, v$, and attends with
   $q$ over the full cache.

## What still costs

There is no Q cache. Only the newest query matters, so old ones are never used again.

The cache turns recomputation into memory: it grows by one entry per layer per token, for every
sequence being served. The next lesson puts a number on it.
