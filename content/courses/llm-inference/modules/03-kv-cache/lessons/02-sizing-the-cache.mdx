## The formula

For every token, every layer stores one key and one value vector per KV head:

$$\text{bytes/token} = 2 \times L \times H_{kv} \times d_{head} \times b$$

- $2$: one K and one V.
- $L$: number of layers.
- $H_{kv}$: KV heads (fewer than query heads with GQA).
- $d_{head}$: head dimension.
- $b$: bytes per element (2 for fp16 and bf16, 1 for fp8).

## A real model

Llama 3 8B: $L = 32$, $H_{kv} = 8$, $d_{head} = 128$, with an fp16 cache.

<Exercise id="llama3-per-token" />

## Per sequence

That is 128 KiB per token. An 8,192-token conversation needs
$131{,}072 \times 8{,}192 \approx 1.07$ GB, just for one sequence's cache.

## Play with it

Total cache = bytes per token x context length x number of sequences. The calculator does the
multiplication and compares the result with your GPU's memory.
