## Add two numbers

The server compiles your function and the tests as one program. Run uses the sample checks. Submit uses the hidden ones, and that is the run that counts.

<Code
  id="add-two"
  devices={["phone","desktop"]}
  language="cpp"
  prompt="Write add(a, b) for two 64-bit integers."
  starter={"long long add(long long a, long long b) {\n    return 0;\n}\n"}
  visibleTests={"#include \"check.h\"\n\nint main() {\n    CHECK(add(2, 3) == 5);\n    return 0;\n}\n"}
  tests={"#include \"check.h\"\n\nint main() {\n    CHECK(add(-4, 10) == 6);\n    CHECK(add(0, 0) == 0);\n    CHECK(add(2000000000LL, 2000000000LL) == 4000000000LL);\n    return 0;\n}\n"}
  solution={"long long add(long long a, long long b) {\n    return a + b;\n}\n"}
  hints={["The tests already define main and CHECK. You only write add.","Use long long. 2e9 + 2e9 does not fit in a 32-bit int."]}
  explanation="The tests and your function compile as one translation unit. CHECK stops at the first miss and prints that line. The last check needs a 64-bit sum."
/>
